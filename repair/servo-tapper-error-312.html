    서보 탭핑기에 에러 312가 뜨면 어떻게 하나요?

    SERVO TAPPING MACHINE · ERROR 312 · TORQUE PROTECTION
    에러 312는 토크 보호 오류입니다. 탭핑할 때 걸린 힘이 「토크 설정」에 넣어 둔 한계값을 넘었다는 표시입니다. 화면에는 「Erry 312」와 함께 「설정 깊이에 닿지 못했다(Tapping has not reached set depth)」는 문장이 뜹니다. 해결 방법은 두 가지입니다. 토크 설정 값을 올리거나, 토크 보호를 끄는 것입니다. 먼저 값을 올려 보시기를 권합니다.

    2. 설정을 바꾸는 동안 모터 척에 손을 대지 마세요.
    3. 탭이 부러졌거나 이상한 소리·진동이 나면 전원 스위치를 끄고 문의해 주세요.

    Steps
    방법 1 — 토크 값 올리기
    STEP 1
    에러 창을 닫고 토크 설정 값을 확인해 주세요
    창 오른쪽 위 ⓧ를 눌러 닫습니다. 첫 화면의 「토크 설정(Torque Setting)」 칸에 지금 걸려 있는 토크 한계값이 N.m 단위로 나옵니다. 나사 규격을 고르면 그 규격의 표준값이 자동으로 들어갑니다.
    STEP 2
    토크 설정 칸을 눌러 값을 올려 주세요
    칸을 누르면 숫자판이 뜹니다. 지금보다 큰 값을 넣고 「Enter」를 누릅니다. 영상에서는 1.2에서 2.0으로 올렸습니다.
    STEP 3
    바뀐 값을 확인하고 다시 탭핑해 주세요
    첫 화면 토크 칸에 새 값이 나오는지 확인합니다. 다시 탭핑해 에러 창이 뜨지 않으면 끝입니다.
    Steps
    방법 2 — 토크 보호 끄기
    STEP 1
    첫 화면 왼쪽 아래 「사용자 파라미터」를 눌러 주세요
    첫 화면 아래 줄 왼쪽 끝의 「User Parameter」 칸입니다.
    STEP 2
    「토크 보호」 단추를 눌러 끄기로 바꿔 주세요
    사용자 파라미터 화면 왼쪽 아래 「Torque Protect」 단추를 누르면 「OFF」로 바뀌고 단추가 빨간색이 됩니다.
    STEP 3
    「뒤로」를 눌러 첫 화면에서 확인해 주세요
    「Back」을 눌러 첫 화면으로 돌아가면 토크 설정 칸에 「OFF」가 나옵니다. 작업이 끝나면 같은 단추로 다시 켜 두세요. 영상에서도 끈 뒤 다시 켭니다.
    If Stuck
    그래도 자주 뜰 때
    탭이 부러지지 않았는데도 토크 보호 창이 자주 뜨면 무부하 토크 기준값을 다시 맞춥니다. 터치스크린의 「무부하 토크」 화면에서 「테스트 시작(Start test)」을 누르면 모터가 최고 속도로 16초 돌고 멈춘 뒤 측정값이 나옵니다. 「데이터 로드(Load data)」를 누르면 그 값이 반영됩니다. 창이 계속 뜨면 기준값을 0.1씩 올려 창이 사라질 때까지 맞춥니다.

    그래도 계속 뜨거나 다른 번호가 뜨면 화면을 사진으로 찍어 보내 주세요. 번호와 숫자가 보이게 찍어 주시면 됩니다.
